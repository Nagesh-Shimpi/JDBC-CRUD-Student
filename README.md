# JDBC-CRUD-Student
# 🎓 JDBC CRUD Student Management System

## 📌 Overview

This project is a **Student Management System** built using **Java JDBC (Java Database Connectivity)**.
It allows users to perform basic database operations like **Create, Read, Update, and Delete (CRUD)** on student records.

The application connects Java with a relational database (like MySQL) and demonstrates how backend systems manage data efficiently.

---

## 🚀 Features

### ➕ Add Student

* Insert new student records into the database
* Stores details like:

  * Student ID
  * Name
  * Age
  * Course

---

### 📋 View Students

* Retrieve and display all student records
* Shows data in a structured format
* Useful for tracking student information

---

### ✏️ Update Student

* Modify existing student details
* Update fields like name, age, or course
* Ensures data remains accurate and up-to-date

---

### ❌ Delete Student

* Remove student records from the database
* Helps maintain clean and relevant data

---

## 🛠️ Technologies Used

* Java
* JDBC API
* MySQL Database
* SQL (Structured Query Language)

---

## 🔗 How It Works

1. Establish connection with the database using JDBC
2. Execute SQL queries (INSERT, SELECT, UPDATE, DELETE)
3. Process results and display output to user
4. Close the database connection

---

## 📂 Project Structure

* `Connection.java` → Handles database connection
* `Student.java` → Model class for student data
* `StudentDAO.java` → Contains CRUD operations
* `Main.java` → Runs the application
